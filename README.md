# Kodama

Kodamaは、英語のシャドーイングを練習するためのWebアプリです。TEDのトークや手持ちの音声を1文ずつに区切り、文ごとに再生しながら練習します。サーバーは使わず、データはすべてブラウザの中に保存します。名前は、山で声を返す「こだま」から取りました。

## できること

教材は、TEDの約5,000本のトークから選ぶか、手持ちの音声・動画ファイルを読み込んで用意します。TEDの一覧では、タイトルや話し手で検索し、長さと和訳の有無で絞り込む形です。音声ファイルは複数まとめて読み込めて、ファイルやフォルダをドロップしても入ります。文字起こしはブラウザの中のWhisperで行い、音声を外部に送ることはありません。

練習画面では、1文ずつの再生と、今の文を追いかける通し再生を選べます。1文ずつのときは、同じ文を3回、または止めるまでくり返せます。速度は0.75倍、1.0倍、1.25倍の3段階です。英文を隠すと、単語の長さの空欄になります。読んでいる文の位置は、いつも画面の中央より少し上です。録音は任意で、お手本と同時に録り、続けて聞くか左右の耳に分けて聞き比べます。

わからない単語は、クリックすると英和辞書の意味が出ます。plannedのような形でも、引くのはもとのplanです。文の和訳は教材を入れた時点で用意し、TEDの日本語訳がある文はその訳を使います。訳がない文はChromeの端末内翻訳で訳し、Chrome以外のブラウザでは文ごとにGoogle翻訳を開く形です。複数の単語を選ぶと、その部分だけを訳せます。

教材一覧は、ファイル管理アプリのリスト表示と同じ形です。フォルダの中にフォルダを作れて、その場で開閉できます。クリックで選択し、CommandキーやShiftキーを押しながらのクリックで複数選択、ダブルクリックで開きます。移動や名前の変更を右クリックのメニューやドラッグで行えるのも、ファイル管理アプリと同じです。気に入った教材には星印をつけて、「お気に入り」にまとめられます。練習した日が続くと、連続日数と練習した日の記録が一覧に出ます。

画面はライトとダークを切り替えられ、最初はライトです。データは1つのファイルにバックアップでき、別の端末でもそのファイルを読み込めば元どおりです。ホーム画面やPCにアプリとして追加すると、通信のないときでも開けます。

キーボードでは、Spaceで再生と停止、左右の矢印キーで文の移動ができます。和訳の表示はJキー、教材のお気に入りはFキーで切り替える仕組みです。録音したあとは、Mキーで自分の声、Cキーでお手本に続けて自分の声、Oキーで重ねて聞けます。

## 開発

```bash
npm install
npm run data
npm run dev
npm test
```

`npm run data` は、TEDのトーク一覧（`public/ted`）と英和辞書（`public/dict`）を作ります。どちらもリポジトリには含めていないので、最初に一度だけ実行が必要です。

公開は Firebase Hosting で、`npm run build` のあとに `npx firebase-tools deploy --only hosting` を実行します。

オフライン用のService Workerは、ビルドのときに `src/sw.js` から `dist/sw.js` を作る仕組みです。開発サーバーでは登録しないので、確かめるときは `npm run build` のあとに `npm run preview` で開きます。

## データの出どころ

TEDのトークは、TEDがCC BY-NC-ND 4.0で公開しているものです。一覧はted.comの非公式なGraphQLから作り、動画と字幕はTEDの配信（hls.ted.com）からブラウザが直接読み込みます。ライセンスの条件により、非営利で使います。

英和辞書は、パブリックドメイン（CC0）の[EJDict-hand](https://github.com/kujirahand/EJDict)です。文字起こしには `onnx-community/whisper-base.en_timestamped` を使い、初回だけ約210MBをダウンロードしてブラウザにキャッシュします。

画面の文章は、[yomiyasu](https://github.com/nanaism/yomiyasu)の方針に沿って書き、同梱のリンターで確かめています。
