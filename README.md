# Shadowing

英語のシャドーイング練習用のWebアプリ。YouTube・TEDの動画や手持ちの音声を1文ずつに区切り、文ごとに再生しながら練習する。

## できること

- **教材の追加**
  - YouTube・TED：URLを貼るだけで、人が作成した英語字幕を自動で取り込む。自動生成の字幕しかない動画、英語字幕がない動画、音声が英語以外の動画は使えない
  - 音声・動画ファイル：ブラウザの中でWhisperが文字起こしし、文ごとに区切る（外部には送信しない）
- **練習**
  - 1文ずつ：文を選んで再生。くり返し（1回・3回・止めるまで）
  - 通し：選んだ文から最後まで、今の文を追いかけながら再生
  - 速度 0.75 / 1.0 / 1.25、英文の表示／隠す（隠すと単語の長さの空欄になる）

キーボード：Space 再生・停止、←→ 文の移動。文をクリックするとそこから再生。

## 開発

```bash
npm install
npm run dev
npm test
```

## 仕組みとメモ

- 字幕の取得は `server/lookup.js`（開発中はViteのサーバーが `/api/lookup` として提供）。YouTubeもTEDもブラウザから直接は読めない（CORS）ため、サーバー側で取りに行く
  - YouTube：公式APIでは他人の動画の字幕を取得できないため、YouTubeのアプリが使う非公式の経路（InnerTube）を使っている。YouTube側の変更で動かなくなることがあり、クラウドのサーバーからだと拒否されることもある
  - TED：ted.com のGraphQLで動画の情報を取り、TEDの字幕ファイル（VTT）を使う。動画はTEDのHLS配信をhls.jsで再生する
- データ（教材と元のファイル）はブラウザのIndexedDBに保存される
- ファイル用の文字起こしモデル（`onnx-community/whisper-base.en_timestamped`、約210MB）は初回だけHugging Faceからダウンロードされ、ブラウザにキャッシュされる
