# Shadowing

英語のシャドーイング練習用のWebアプリ。TEDのトークや手持ちの音声を1文ずつに区切り、文ごとに再生しながら練習する。サーバーは使わず、データはすべてブラウザの中に保存される。

## できること

- **教材（ファイル管理アプリのような一覧）**
  - フォルダの中にフォルダを作れる。リスト表示で、フォルダはその場で開閉できる。名前・長さ・最終練習で並べ替え
  - クリックで選択、⌘／Shift＋クリックで複数選択、ダブルクリックで開く。右クリックで 開く／名前を変更／移動／お気に入り／削除
  - ドラッグでフォルダや上の階層表示に移動。「移動…」でフォルダを選んで移動
  - 音声・動画ファイルを複数まとめて読み込める（選ぶか、ファイルやフォルダごとドロップ）。フォルダの構成はそのまま。1つずつ順に文字起こしし、進み具合を表示
  - TEDから追加：約5,000本のトークをサムネイル付きで検索し、長さ・和訳の有無で絞り込む（TEDのURLを貼っても探せる）
  - スマホではタップで開き、「選択」で複数選択
- **練習**
  - 1文ずつ（くり返し 1回・3回・止めるまで）／通し（今の文を追いかけながら再生）。今読んでいる文は、いつも画面の中央より少し上に来る
  - 速度 0.75 / 1.0 / 1.25、英文の表示／隠す（隠すと単語の長さの空欄になる）
  - 録音（任意）：お手本と同時に録音し、お手本／自分／続けて／重ねて（左耳にお手本、右耳に自分）で聞き比べる
- **わからないところ**
  - 単語をクリック（タップ）すると英和辞書の意味を表示。活用形はもとの形も引く（planned → plan）
  - 文の和訳：教材を追加した時点で全文ぶんを用意する。TEDの日本語訳（人による翻訳）があればそれを使い、なければChromeの端末内翻訳で機械翻訳して保存（裏で進み、終わった文から表示）。端末内翻訳がないブラウザではGoogle翻訳へのリンク
  - 複数の単語を選ぶと、その部分を翻訳
- **お気に入り**：教材の ☆。「お気に入り」タブにまとまる
- **続ける工夫**：連続日数・今日の練習量・2週間の記録

キーボード：Space 再生・停止、←→ 文の移動、J 和訳、F 教材をお気に入り、M／C／O 自分／続けて／重ねて（録音後）

## 開発

```bash
npm install
npm run data   # TEDの一覧と辞書を作る（public/ted, public/dict）
npm run dev
npm test
```

## データの出どころ

- TED：TEDのトークはTEDがCC BY-NC-ND 4.0で公開しているもの。一覧はted.comのGraphQL（非公式）から `npm run data` で作り、動画・字幕はTEDの配信（hls.ted.com）からブラウザが直接読み込む。非営利で使うこと
- 英和辞書：[EJDict-hand](https://github.com/kujirahand/EJDict)（パブリックドメイン CC0）
- 文字起こし：`onnx-community/whisper-base.en_timestamped`（初回だけ約210MBをダウンロードし、ブラウザにキャッシュ）
