# Shadowing

英語のシャドーイング練習用のWebアプリ。YouTubeの動画か手持ちの音声・動画ファイルを1文ずつに区切り、お手本を流しながら録音して、自分の声と聞き比べる。

## できること

- **教材の追加**
  - YouTube：動画のURLと文字起こし（YouTubeの「文字起こしを表示」からコピーしたもの、または .srt / .vtt）を貼り付ける
  - 音声・動画ファイル：ブラウザの中でWhisperが文字起こしし、文ごとに区切る（外部には送信しない）
- **練習**
  - 1文ずつ：お手本の再生と同時に録音が始まり、文が終わると自動で止まる
  - 通し：今の文から最後まで流しながら録音し、あとで1文ずつ聞き比べる
  - 速度 0.75 / 1.0 / 1.25、英文の表示／隠す（隠すと単語の長さの空欄になる）
- **聞き比べ**：お手本／自分／続けて（お手本→自分）／重ねて（同時に再生。ファイル教材では左耳にお手本、右耳に自分）

キーボード：Space 録音・停止、←→ 文の移動、Enter お手本、M 自分、C 続けて、O 重ねて

## 開発

```bash
npm install
npm run dev
npm test
```

## メモ

- データ（教材・元のファイル・録音）はすべてブラウザのIndexedDBに保存される。サーバーはない
- 文字起こしモデル（`onnx-community/whisper-base.en_timestamped`、約210MB）は初回だけHugging Faceからダウンロードされ、ブラウザにキャッシュされる。WebGPUが使えればWebGPU、なければWASMで動く
- スピーカーで練習するとお手本の音も録音されるので、ヘッドホン推奨
